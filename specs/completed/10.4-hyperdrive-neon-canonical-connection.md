## What We're Building

Move HAETSAL-owned canonical Neon/Postgres access to Cloudflare Hyperdrive,
using the current Worker-native Hyperdrive connection-string path and a native
Postgres driver.

This session changes only the connection layer for canonical Postgres-backed
stores. It does not change canonical memory semantics, Hindsight behavior,
AI Search, graph projections, consolidation logic, schemas, or deployment.

## Implementation Plan

1. Create a small Postgres SQL adapter that:
   - takes a connection string
   - uses `pg`
   - supports tagged parameterized queries
   - supports raw schema DDL statements
   - supports transactions for existing multi-statement writes
2. Resolve canonical connection strings in this order:
   - `env.HYPERDRIVE_CANONICAL.connectionString`
   - `env.CANONICAL_POSTGRES_CONNECTION_STRING`
   - otherwise throw
3. Switch canonical and compiled store constructors to use the adapter.
4. Add `HYPERDRIVE_CANONICAL` to `wrangler.toml` and `src/types/env.ts`.
5. Regenerate `src/types/cloudflare-env.generated.d.ts`.
6. Update `.dev.vars.example` so local canonical fallback uses
   `CANONICAL_POSTGRES_CONNECTION_STRING` instead of implicitly sharing the
   Hindsight secret.
