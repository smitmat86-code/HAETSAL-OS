## What We're Building

Build the baseline dossier for the post-Hindsight Cloudflare upgrade.

This session does not upgrade runtime code. It establishes the exact current
state so the next sessions can remove Hindsight and modernize Cloudflare
without guessing.

The deliverable is a written baseline report at:

- `docs/implementation-plans/post-hindsight-baseline-report.md`

That report should answer:

- which HAETSAL working tree is the active/latest tree
- what Hindsight references still exist and how risky each removal is
- which Cloudflare primitives are configured today
- which Cloudflare primitives are planned by the roadmap
- where Neon/Postgres is already the canonical store
- where memory write/read/context flows exist today
- what has to be reconciled before Phase 1 begins

---

## Why This Session Exists

The strategic direction is now clear:

- Hindsight should be removed from HAETSAL.
- Neon/Postgres should remain the canonical database.
- Cloudflare should provide the agent runtime, ingress, coordination,
  edge-facing retrieval, and optional accelerators.
- GBrain-style retrieval and AI Search should be synthesized rather than
  treated as mutually exclusive.
- Markdown should exist as authored truth and compiled context, not as the only
  system of record.

But the project has multiple historical branches, local reference checkouts,
older Cloudflare assumptions, and partially completed planning docs. We need a
ground-truth baseline before making runtime changes.

This session turns the large roadmap into an executable starting point.

## THE Brain Laws Check

### Law 1: One Public Face

Do not add a new public brain surface in this session. Inventory existing
surfaces and document what should remain canonical.

### Law 2: Zero-Knowledge

Do not introduce new transcript dumps, raw-content caches, or duplicate durable
stores. This session is documentation and inventory only.

### Law 3: Agent Write Policy

Do not broaden agent write authority. If existing tools can write memory, record
that behavior and its storage path.

### Law 4: Post-Hindsight Direction

Treat Hindsight as deprecated. Do not add new Hindsight dependency, API, schema,
configuration, or compatibility layer.
