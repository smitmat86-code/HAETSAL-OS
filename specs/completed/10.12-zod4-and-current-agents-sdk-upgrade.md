## Canonical Memory Confirmation

Canonical HAETSAL memory remains Postgres/R2 via Hyperdrive.

The stable memory surface remains `src/tools/brain-memory-surface.ts`, which
registers `registerCanonicalMemoryTools()`.

The canonical write path remains the existing evidence pipeline:

1. `capture_memory`
2. `captureExternalClientMemory()`
3. `retainViaService()`
4. `retainContent()`
5. `captureThroughCanonicalPipeline()`
6. encrypted body payloads in R2
7. canonical metadata through `getCanonicalMemoryStore()`
8. `PostgresCanonicalMemoryStore` through `createCanonicalPostgresSql(env)`
9. `env.HYPERDRIVE_CANONICAL.connectionString` first, then
   `env.CANONICAL_POSTGRES_CONNECTION_STRING` fallback

The MCP agent's local `mcp_agent_session` Durable Object SQLite table remains
tenant/bootstrap working state only. It is not a Cloudflare Agents Session
store and is not canonical memory.
