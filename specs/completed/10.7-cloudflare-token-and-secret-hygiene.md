## Cloudflare Permission Plan

Sources checked:

- Cloudflare API token permissions:
  `https://developers.cloudflare.com/fundamentals/api/reference/permissions/`
- Cloudflare API token creation guidance:
  `https://developers.cloudflare.com/fundamentals/api/get-started/create-token/`
- Hyperdrive list/get API:
  `https://developers.cloudflare.com/api/resources/hyperdrive/subresources/configs/methods/list/`
  and
  `https://developers.cloudflare.com/api/resources/hyperdrive/subresources/configs/methods/get/`
- Workers script upload API:
  `https://developers.cloudflare.com/api/go/resources/workers/subresources/scripts/methods/update`
- Workers script secrets API:
  `https://developers.cloudflare.com/api/resources/workers/subresources/scripts/subresources/secrets/methods/list/`
- Wrangler deploy dry-run docs:
  `https://developers.cloudflare.com/workers/wrangler/commands/workers/`

Minimum token plan for this repo:

| Workflow | Minimum account permission | Notes |
|----------|----------------------------|-------|
| Hyperdrive read/list/get | `Hyperdrive Read` | Cloudflare API accepts `Hyperdrive Read` or `Hyperdrive Write`; read is the least-privilege choice. |
| Worker deploy / upload | `Workers Scripts Write` | Dashboard label may appear as Workers Scripts Edit; API docs name the accepted permission `Workers Scripts Write`. |
| Workers secrets read/list/get | `Workers Scripts Read` | API also accepts `Workers Tail Read` or `Workers Scripts Write` for listing secrets, but `Workers Scripts Read` is the least-privilege scripts permission. |
| Workers secrets write/delete/bulk update | `Workers Scripts Write` | Needed only if this token will create, update, delete, or bulk patch Worker secrets. |

For future reliable automation, create or roll a token scoped to the target
Cloudflare account with:

- Account: `Hyperdrive Read`
- Account: `Workers Scripts Write`
- Optional if separating duties: a read-only inspection token with Account:
  `Hyperdrive Read` and Account: `Workers Scripts Read`
